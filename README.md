## ⚠️ 先读这一段：这批资料的"代际问题"

仓库里的资料**绝大部分是第 1 版教材（12 章体系）时代的产物**，而你要考的是 **2025 年起启用的第 2 版教程（24 章体系）**。

**这意味着：**

1. **老版整整 12 章的内容，在新教材里被压缩成了第 12 章（信息系统服务管理）这一章**。本仓库的 `02-思维导图`、`04-模拟题/章节模拟题`、`05-重点梳理` 里的口诀与重点，覆盖的是新考纲中约 **1 章 + 15/16/24 章的一部分**，粗估对应 10~15 分。
2. **2017-2023 年真题全部基于第 1 版考纲**。它们的价值在于：**熟悉题型、案例答题套路、论文行文结构**——而不是押知识点。做真题时请随手标注"这题对应新教材第几章"，标不出来的就是老版专属考点，可以降权。
3. **基础篇 10 分 + 方法篇 25 分 + 实践篇 15 分 = 50 分**，原仓库几乎没有对应资料。为此我额外从**高项（信息系统项目管理师）第 4 版仓库**取了配套资料，放在 `07-高项借用/`，已验证是**第 4 版新教材**内容（见下）。
4. 即便如此，**方法篇的第 4、5、6 章（信息系统规划 / 应用系统规划 / 云资源规划）没有任何外部资料可借**，这是纯粹的新内容，只能靠正版第 2 版教程精读。它们恰好也是这门考试的名字所在——大概率是命题重点。

> 关于 **AIOps 智能运维**：24 章目录中**没有以 AIOps 命名的独立章节**，它应作为知识点分布在能力篇（12 信息系统服务管理 / 16 资源与工具管理）内。请以你买到的正版教材目录为准。

**结论：本工作区 = 题型训练场 + 论文素材库 + 老版知识底座 + 高项补丁；新教材方法篇必须以正版教程为主线。** 68 天计划已按此思路编排，见 `study-plan.md`。

### 网页版（推荐）

```bash
node serve.js                # 本地使用：启动后自动打开 http://127.0.0.1:3000
node serve.js --port 8080    # 换端口（也可用 PORT 环境变量）
node serve.js --no-open      # 不自动开浏览器
```

键盘 **A/B/C/D** 或 **1/2/3/4** 作答，**Enter** 下一题，**Esc** 交卷。
支持自由练习（按题型/年份/章节筛选）、错题本、限时模考（75 题 75 分钟倒计时）、统计页（含正确率走势图）、考试倒计时。深浅色跟随系统。

**部署到服务器**（错题本可写，属个人数据，对外监听必须设置口令，否则拒绝启动）：

```bash
QUIZ_TOKEN=你的口令 node serve.js --host 0.0.0.0 --port 3000 --no-open
```

网页首次打开会要求输入口令，之后存在浏览器 localStorage 里；手机、电脑共用同一份错题本与练习历史（`wrong.json` 存在服务器上，天然多端同步）。这是单人应用，不要把口令分享给别人一起刷——写入会互相覆盖。

systemd 常驻示例（`/etc/systemd/system/syslplan.service`）：

```ini
[Unit]
Description=Syslplan quiz web
After=network.target

[Service]
WorkingDirectory=/opt/Syslplan
Environment=QUIZ_TOKEN=你的口令
ExecStart=/usr/bin/node serve.js --host 0.0.0.0 --port 3000 --no-open
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

建议再套一层 Nginx/Caddy 做 HTTPS（口令是明文头 `X-Quiz-Token` 传输的，裸 HTTP 只适合内网/防火墙白名单场景）。记得定期备份 `wrong.json`。

### 命令行版

```bash
node quiz.js                 # 交互菜单
node quiz.js --year 2019     # 按年份刷题
node quiz.js --random 20     # 随机抽 20 题
node quiz.js --wrong         # 只刷错题本
node quiz.js --stats         # 正确率统计与历史曲线
node quiz.js --list          # 题库概况
```

题库 `questions.json` 共 **644 题**：真题 337（2017下 68、2018上 62、2019上 75、2020下 5、2022上 45、2023上 40、2024下 42）、模拟卷 140、章节练习 143、复习题 24。答错自动记入 `wrong.json`，连续答对 2 次移出错题本。2022/2023/2024 真题是人工从网上公开的解析文章核对补录的，不是全部 75 题都有，详见《需人工处理清单.md》。

`tools/` 下的三个脚本（纯 Node，无第三方依赖）：

| 脚本 | 用途 |
|---|---|
| `tools/pdftext.js` | PDF 文本提取器（FlateDecode / 对象流 / Type0 CID 字体 / ToUnicode CMap / 按坐标还原换行）。也可单独用：`node tools/pdftext.js 某文件.pdf 1 5` |
| `tools/survey.js` | 批量判定 PDF 是文本型还是扫描型：`node tools/survey.js 01-真题` |
| `tools/extract-questions.js` | 从 01-真题 与 04-模拟题 生成 `questions.json`，支持 4 种版面（会覆盖，手动补录前请备份） |
| `tools/validate-questions.js` | 题库体检：乱码、空选项、重复选项、答案分布偏斜 |
| `serve.js` + `web/index.html` | 网页版刷题（本地服务，与命令行共用 questions.json / wrong.json） |
